# Job Apply Tool - Frontend

React + TypeScript + TailwindCSS web dashboard for the Job Apply Tool.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```bash
cp .env.example .env
```

3. Start development server:
```bash
npm run dev
```

The app will be available at http://localhost:5173

## Features

- **Dashboard**: Real-time statistics and charts
- **Application Queue**: View and manage queued jobs
- **Pending Questions**: Answer questions with AI suggestions
- **Daemon Control**: Monitor daemon status and logs

## Development

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Tech Stack

- React 18
- TypeScript
- TailwindCSS
- React Query (TanStack Query)
- Recharts
- Axios
- React Router
- Lucide Icons
